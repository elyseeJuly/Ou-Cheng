# 偶成 (Ou Cheng) — 领域规则与格律校验规范 (DOMAIN_RULES.md)

**版本**：v0.5.1  
**定位**：诗词格律、韵书、词牌与专业规则校验权威说明。

---

## 一、 韵书系统与古音/今音回退逻辑

偶成支持三大韵书系统：
1. **词林正韵 (`ci_lin`)**：宋词创作标准；
2. **平水韵 (`ping_shui`)**：近体诗创作标准；
3. **中华新韵 (`xin_yun`)**：现代普通话读音标准。

### 古韵书缺字规则 (P1-5 规范)
* 在 `ping_shui` 与 `ci_lin` 模式下，若字未收录于古韵书，引擎严格返回 `'unknown'`，前端提示“平仄待考”，**绝不强制回退现代拼音作为确定结论**；
* 仅在 `xin_yun` 模式下，允许通过现代汉语拼音一二声判定为平、三四声判定为仄。

## 二、 词牌与近体诗校验规则

### 1. 多音字安全判定 (P1-4 规范)
格律检查直接基于当前选中韵书判定 `getTone(char, rhymeBook)`：
* 返回单值（`'P'` | `'Z'`）：确定读音；
* 返回数组（`['P', 'Z']`）：多音字，只要其中一个符合预期平仄即标记为 `warn`（可读）。

### 2. 词牌缺失行与违规惩罚 (P2-2 规范)
词牌缺失句的违规数（`violationCount`）按缺失句 Pattern 的真实字符数精确累加求和：
`violationCount = sum(Array.from(missingLinePattern).length)`。

缺失字符只在格律单元格中计数一次，不得再以“缺失行惩罚”二次累加；近体诗与词牌均遵循此规则。

### 3. 多韵字定韵
首韵字只对应一个韵部时可自动锁定；对应多个韵部时必须展示候选并等待用户选择，不得默认取第一项。

### 4. 十四行诗校验提示 (P2-3 规范)
十四行诗检查器（`checkSonnet`）自动校验 14 行行数，韵式（如 ABAB CDCD EFEF GG）为创作辅助参考提示，不强行做自动韵脚扣分。

---

## 三、 自定义体例与字数范围 (P1-7 规范)

`PoemForm.charsPerLine` 支持单值与范围元组：
* 数字（如 `5`）：精确匹配 5 字；
* 范围元组（如 `[5, 7]`）：校验文本行字数需在 `5 <= actual <= 7` 范围内。
通用校验函数为 `checkCharsPerLine(actualLength, rule)`。
